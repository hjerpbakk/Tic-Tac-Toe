# Tic-Tac-Toe

Old command line Tic Tac Toe in C++ with a computer opponent. One Xcode command line tool project, all code in `Tic Tac Toe/main.cpp`.

## Build and test

```bash
xcodebuild -project "Tic Tac Toe.xcodeproj" -scheme "Tic Tac Toe" -destination 'platform=macOS' -quiet build
```

There is no test suite.
